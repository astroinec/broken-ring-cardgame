# M3 重玩性、局外解锁与随机化协议

> 目标：让连续远征拥有不同路线、不同卡池与不同构筑方向；局外进度只解锁选择，不提供永久数值加成。

---

## 一、问题基线

当前审计：

- 改造前起始牌组10张，其中8张是基础攻防，占80%；改造后为7张，其中5张是重复基础攻防；
- 节点6模拟中，初始4种卡占全部出牌67.5%，《校准击》单卡45.8%；
- 前3层奖励池仅开放4/15张奖励牌，重复率高；
- 正常“新远征”固定使用种子73103，实际重开内容完全复现；
- 地图拓扑只有1种，理论路线组合8种；
- 没有独立局外档案，通关后不会解锁内容。

本阶段不是继续堆纯伤害/格挡牌，而是先建立可持续扩展的重玩框架。

---

## 二、局外进度原则

独立文件：`user://broken_ring_profile_v1.json`

```json
{
  "profile_schema": 1,
  "runs_started": 0,
  "boss_reached": 0,
  "wins": 0,
  "read_original_wins": 0,
  "highest_depth": 0,
  "unlock_tier": 0,
  "recent_event_ids": []
}
```

不允许局外永久增加：生命、稳定度、基础伤害、初始抽牌、商店折扣。

允许解锁：卡牌、事件变体、地图模板、起始模块（后续）。

---

## 三、四级解锁轨道

### U0：初始开放

奖励池：断句、留白、索引重排、未署名的援护、裂隙挥击、强制稳定、临界许可、延迟防线、倒计刻痕、开封令、复述、复写护式。

从第一局起即可体验超载、封存、回响、牌堆控制和主动开封；《临界许可》让首次Boss挑战具备可学习的裂解反制，不把关键解法锁在失败之后。

### U1：首次抵达删名者

解锁：预写结局、崩解协议、同音异义。

### U2：首次通关

解锁新卡：

1. **反向索引**（律式/普通/1）：从弃牌堆选择1张非状态牌加入手牌。消逝。
2. **删去冗句**（律式/普通/0）：选择手牌中另一张牌并消逝；抽2张牌。消逝。
3. **缺名仲裁**（守式/罕见/1）：清除全部缺名；每清除1层获得4格挡；若至少清除1层，抽1张牌。消逝。

### U3：读取被删原文，或累计通关3次

解锁新卡：

1. **第十种答案**（攻式/罕见/2）：造成8点伤害；封存区每有1张牌，额外造成4点伤害；随后所有封存牌倒计时减少1。
2. **回声室**（律式/罕见/1）：抽1张牌；本回合下一次成功回响的数值额外提高50%。消逝。
3. **借名执行**（攻式/普通/1）：造成5点伤害；每存在一种缺名，额外造成3点伤害；随后每种缺名各清除1层。

## 四、每局种子

- 标题页“开始新远征”使用运行时随机种子；
- 地图页和存档摘要显示种子；
- 标题页提供“使用种子复现”输入框；
- 同一种子+同一解锁层级必须完整复现；
- 单局开始后冻结`unlock_tier`和卡池，局外新增解锁不会改变已保存远征。

---

## 五、地图随机化

保持9层节奏和最终Boss，但至少提供3种模板：

- **档案路线**：事件和商店较多；
- **裂隙路线**：战斗和精英较多；
- **校准路线**：休整、锻造与混合分叉较多。

要求：

- 节点数、分叉宽度和类型随种子变化；
- 非Boss节点只连接下一层的部分节点，不再全部互连；
- 每个下一层节点至少有1条前驱；
- 两个事件节点从已解锁事件池独立、无放回抽取；
- 30种子结构指纹至少12种，事件有序对至少12种。

---

## 六、奖励与商店抽样

三选一不再纯随机重复：

1. 1张与当前牌组标签最匹配的协同牌；
2. 1张不同构筑轴的牌；
3. 1张通用牌或罕见牌。

规则：

- 只从本局冻结的解锁池抽取；
- 同一奖励中不重复；
- 本局已出现过的卡牌降低权重；
- 每张非基础牌在牌组中达到2张后显著降低权重；
- 前3层也允许出现律式和机制牌；
- 商店至少有1张本局战后奖励尚未出现的牌。

卡牌定义增加构筑标签：`overload`、`seal`、`echo`、`missing_name`、`deck_control`、`general`。

### 休整节点的额外获取途径

只靠战后三选一，7张起始牌组每局仅能增加3～4张，基础攻防仍会主导出牌。因此休整节点提供第四个选项：

- **搜寻残页**：按当前牌组主导标签，从本局冻结卡池获得1张牌；
- 优先给出本局尚未出现过的牌；
- 完全由节点种子决定，可复现；
- 与恢复生命、升级、回收墨晶互斥，仍是一次真实取舍。

## 七、UI

标题页新增“回收者档案”：

- 已开始远征、抵达Boss、通关次数；
- 当前解锁层级；
- 下一解锁条件；
- 已解锁卡牌数；
- 最近一次新解锁卡包。

结算页显示本局触发的解锁和新卡预览。

档案页新增“卡牌图鉴”：已解锁显示完整文本，未解锁只显示条件和剪影名称。

## 八、验收指标

- 新局不再固定种子；同seed可复现；
- 30种子地图结构指纹≥12，事件有序对≥12；
- 四级解锁按条件推进，重复结算不重复解锁；
- Profile损坏安全降级，不影响远征存档；
- U0/U1/U2/U3奖励池严格过滤；
- 新增6张牌规则、选择取消、升级和存档均有测试；
- 硬阈值：Boss前成长战斗中真正重复的基础攻防占比<40%（实际34.5%）；
- 《校准击》单卡出牌占比目标<25%（实际5.7%）；
- 初始4种卡占比只作参考记录（实际57.8%），因为其中《越界读取》《余震》本身是机制牌；
- 7张初始牌组下，最终牌组平均9.5～14张（实际11.34）；
- 不以局外永久数值加成提高胜率。

## 九、实现约束

规则层必须提供统一的 `can_play_card(index)`：同时判断状态牌、稳定度和「是否存在合法选择目标」。

原因：新增的《反向索引》《删去冗句》需要弃牌堆或另一张手牌。如果缺目标时仍允许打出，会出现"付费却无效果"甚至"免费抽牌"。而所有模拟的出牌循环也必须用它做前置判断，否则 `play_card` 返回 false 会让回合不推进，直接造成死循环。
